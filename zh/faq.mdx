# 常见问题 (FAQ)

## 账户与计费

<AccordionGroup>
  <Accordion title="如何获取 API 密钥？" icon="key">
    登录后打开 [API 密钥](https://sigrunai.com/console?tab=apikeys) 创建。密钥只显示一次，请立即保存。
  </Accordion>
  <Accordion title="API 基础地址是什么？" icon="link">
    与控制台同源，例如 `https://sigrunai.com`（不含路径）。接口路径为 `/v1/...`。在 API 密钥页可直接复制基础地址。
  </Accordion>
  <Accordion title="如何计费？" icon="credit-card">
    预付费积分。先在 [充值](https://sigrunai.com/recharge) 页面充值。单价以 [模型目录](/zh/api-reference/common/model-catalog) 为准；实际扣费看创建/查询响应里的 `data.cost`。
  </Accordion>
</AccordionGroup>

## 任务调用

<AccordionGroup>
  <Accordion title="支持哪些模型？" icon="cubes">
    以目录实时返回为准。当前常见为 `gpt-image-2`（及 low/medium/high 计费档）、`nano-banana-2` / `nano-banana-2.1` / `nano-banana-pro`（按 `resolution` 计费）、`omni-10s`、`seedance2.0-md`、`sd2-480p-ac` / `sd2-720p-ac`、`sd2-720p-dl`、`sd2-720p-db`、`sd2.0-mini-720p`、`seedance2.5-30s`、`sd2.5-720p-ac`、`wan3-480p-20s-ac`。
  </Accordion>
  <Accordion title="为什么任务失败？" icon="circle-exclamation">
    常见原因：参数不符合该模型约束、余额不足、或服务短暂不可用。请查看查询响应中的 `error_message`。
  </Accordion>
  <Accordion title="什么是智能排队？" icon="clock">
    创建图片或视频任务时可传 `smart_queue: true`。默认关闭，创建后立刻提交。开启后，若该模型近期成功率过低，任务会先保持 `queued`，恢复后再提交（最长约 2 小时，超时退款）。详见 [智能排队](/zh/api-reference/common/smart-queue)。
  </Accordion>
  <Accordion title="如何拿到生成结果？" icon="magnifying-glass">
    创建后轮询 `GET /v1/images/{task_id}` 或 `GET /v1/videos/{task_id}`。`status` 为 `completed` 时读取 `result.image_url` 或 `result.video_url`。结果链接约保留 3 天。
  </Accordion>
</AccordionGroup>
