## 欢迎

欢迎来到 AI Platform API 参考文档。我们的 API 允许您通过编程方式使用 Sora、VEO 和 GPT Image 2 等尖端模型生成高质量的视频和图片。

## API 基础地址

文档与示例中的请求主机统一写作：

```text
https://api.example.com
```

调用时请将其替换为**实际的 API 基础网站地址**（即真实 Base URL）。路径保持不变，例如：

| 文档示例 | 实际请求 |
| --- | --- |
| `https://api.example.com/api/open-api/v1/videos` | `https://<你的API基础地址>/api/open-api/v1/videos` |

同步生图直连主机若写作 `https://img.example.com`，同样替换为实际生图服务地址。
