## 欢迎

欢迎使用 AI Platform OpenAPI。你可以通过统一的异步接口生成图片与视频，再用 `task_id` 轮询结果。

当前可用模型（以 [模型目录](/zh/api-reference/common/model-catalog) 实时返回为准）：

| 类型 | `model` | 说明 |
| --- | --- | --- |
| 图片 | `gpt-image-2` | 异步生图；可用 `quality` 或 `gpt-image-2-low` / `medium` / `high` 计费档 |
| 图片 | `nano-banana-2` / `nano-banana-2.1` / `nano-banana-pro` | 异步生图；用 `resolution` 选择档位并计费 |
| 视频 | `omni-10s` | Omni 10s；固定 10 秒、720p |
| 视频 | `seedance2.0-md` | 5 / 10 / 15 秒 |
| 视频 | `sd2-480p-ac` / `sd2-720p-ac` | 4–15 秒；按次两档 |
| 视频 | `seedance2.5-30s` | 固定 30 秒 |
| 视频 | `sd2.5-720p-ac` | 4–30 秒；固定 720p；按次 |

## API 基础地址

OpenAPI 与控制台**同源**。文档示例使用：

```text
https://sigrunai.com
```

控制台 **API 密钥** 页展示的「API 基础地址」即为该 origin（不含路径）：

```text
https://sigrunai.com
```

接口路径以 `/v1` 开头。若你部署在自有域名，将主机替换为当前站点 origin，路径保持不变。

| 能力 | 方法与路径 |
| --- | --- |
| 创建图片任务 | `POST /v1/images` |
| 查询图片任务 | `GET /v1/images/{task_id}` |
| 创建视频任务 | `POST /v1/videos` |
| 创建 Omni 10s 视频 | `POST /v1/videos`（`model=omni-10s`） |
| 查询视频任务 | `GET /v1/videos/{task_id}` |
| 上传文件 | `POST /v1/files` |
| 模型目录（无需 Key） | `GET /v1/model/catalog` |
| 查询用户余额 | `GET /v1/user/balance` |
| 查询 Key 额度 | `GET /v1/key/balance` |

## 认证

除模型目录外，所有 OpenAPI 请求在请求头携带：

```http
Authorization: Bearer <你的 API Key>
```

在控制台 [API 密钥](https://sigrunai.com/console?tab=apikeys) 创建密钥。
