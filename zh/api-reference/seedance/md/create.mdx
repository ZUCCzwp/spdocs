---
title: 'Seedance 2.0 MD'
openapi: 'POST /v1/videos'
---

创建 Seedance **2.0 MD** 视频任务。路径为统一的 `POST /v1/videos`，`model` 设为 `seedance2.0-md`。完成后从 [查询视频任务](/zh/api-reference/common/query) 的 `result.video_url` 取片。

## 模型

| `model` | 计费 | 时长 |
| --- | --- | --- |
| `seedance2.0-md` | `per_task`（按次） | **5** / **10** / **15** 秒 |

输出固定 **720p**。`resolution` 无效。不支持首尾帧。

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | `seedance2.0-md` |
| `prompt` | string | 是 | 最多 **6000** 字符 |
| `duration` | int | 是 | 仅 **5**、**10**、**15**；默认 5 |
| `aspect_ratio` / `ratio` | string | 否 | `1:1`、`3:4`、`4:3`、`9:16`、`16:9`、`21:9` |
| `images` / `reference_images` | string[] | 否 | 参考图，最多 **9** 张 |
| `videos` / `reference_videos` | string[] | 否 | 参考视频，最多 **3** 个 |
| `audios` / `reference_audios` | string[] | 否 | 参考音频，最多 **3** 段 |

参考素材须为公网 `https://` URL，不要传 base64。图片不支持 GIF。

## 示例

```bash
curl -X POST 'https://aiplatform.ccwu.cc/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-md",
    "prompt": "产品旋转展示，棚拍灯光",
    "duration": 5,
    "aspect_ratio": "1:1",
    "images": ["https://example.com/product.png"]
  }'
```
