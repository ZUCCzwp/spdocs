---
title: '创建 Seedance 2.5 视频'
openapi: 'POST /v1/videos'
---

异步生成 **Seedance 2.5** 视频。使用统一入口 `POST /v1/videos`，直接传计费键 `sd2.5-480p` / `sd2.5-720p` / `sd2.5-1080p`。成功返回 `task_id`，用 [查询视频任务](/zh/api-reference/common/query) 轮询，完成后从 `result.video_url` 取片。

## 模型

| `model` | 说明 | 时长 | 分辨率 |
| --- | --- | --- | --- |
| `sd2.5-480p` | 计费键：480p | **5–30** 秒 | `480p` |
| `sd2.5-720p` | 计费键：720p | **5–30** 秒 | `720p` |
| `sd2.5-1080p` | 计费键：1080p | **5–30** 秒 | `1080p` |

计费方式为 `per_second`（按秒）。费用 = 该分辨率单价 × 请求时长。实际单价以 [模型目录](/zh/api-reference/common/model-catalog) 与响应中的 `cost` 为准。

## 模式判定

| 模式 | 传参 |
| --- | --- |
| 文生视频 | 不传 `images` / `videos` / `audios`，或全部传空数组 |
| 参考内容生成 | 传入参考图、参考视频和/或参考音频 |

本接口**不支持**首尾帧字段。

## 参考素材限制

| 类型 | 数量上限 |
| --- | --- |
| 图片 | **9** |
| 视频 | **3** |
| 音频 | **1** |

参考素材须为公网可访问的 URL。

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | `sd2.5-480p` / `sd2.5-720p` / `sd2.5-1080p` |
| `prompt` | string | 是 | 生成描述，1–5000 字 |
| `duration` / `seconds` | int \| string | 否 | **5–30**；未传时默认 **5**。字符串亦可（如 `"10"`） |
| `aspect_ratio` / `ratio` | string | 否 | `16:9`、`9:16`、`1:1`、`4:3`、`3:4`；默认 `9:16` |
| `images` / `reference_images` | string[] | 否 | 参考图 URL，最多 **9** 张 |
| `videos` / `reference_videos` | string[] | 否 | 参考视频 URL，最多 **3** 个 |
| `audios` / `reference_audios` | string[] | 否 | 参考音频 URL，最多 **1** 段 |
| `smart_queue` | bool | 否 | 默认 `false`。为 `true` 时，近期成功率过低会先保持 `queued`，恢复后再提交（最长约 2 小时）。详见 [智能排队](/zh/api-reference/common/smart-queue) |

## 示例

### 文生视频

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2.5-720p",
    "prompt": "花园里一只猫穿过花丛，电影质感",
    "aspect_ratio": "16:9",
    "duration": 8
  }'
```

### 参考图与参考视频

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2.5-1080p",
    "prompt": "参考图片中的人物和视频中的动作，生成花园中的新镜头",
    "aspect_ratio": "9:16",
    "duration": 5,
    "images": ["https://example.com/person.jpg"],
    "videos": ["https://example.com/motion.mp4"]
  }'
```

## 响应

创建成功后返回统一任务结构（含 `task_id`、`status`、`cost` 等）。`data.model` 为计费键（如 `sd2.5-720p`）。任务完成后通过查询接口读取 `result.video_url`。
