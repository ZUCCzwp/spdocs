---
title: 'Seedance 2.5 30s'
openapi: 'POST /v1/videos'
---

创建 Seedance **2.5 30s** 视频任务。路径为统一的 `POST /v1/videos`，`model` 设为 `seedance2.5-30s`。完成后从 [查询视频任务](/zh/api-reference/common/query) 的 `result.video_url` 取片。

## 模型

| `model` | 计费 | 时长 |
| --- | --- | --- |
| `seedance2.5-30s` | `per_task`（按次） | 固定 **30** 秒 |

请求中的 `duration` 若传入必须为 `30`；省略时默认 30。不支持首尾帧。

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | `seedance2.5-30s` |
| `prompt` | string | 是 | 最多 **5000** 字符 |
| `aspect_ratio` / `ratio` | string | 否 | 仅 `16:9`、`9:16`；默认 `9:16` |
| `images` / `reference_images` | string[] | 否 | 参考图，最多 **30** 张 |
| `videos` / `reference_videos` | string[] | 否 | 参考视频，最多 **10** 个 |
| `audios` / `reference_audios` | string[] | 否 | 参考音频，最多 **10** 段 |

参考素材须为公网 `https://` URL。

## 示例

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.5-30s",
    "prompt": "一只猫在草地上奔跑，跟拍镜头",
    "aspect_ratio": "9:16",
    "images": ["https://example.com/cat.png"]
  }'
```
