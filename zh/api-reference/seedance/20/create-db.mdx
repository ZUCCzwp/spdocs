title: 'Seedance 2.0 DB'
openapi: 'POST /v1/videos'
---

创建 Seedance **2.0 DB** 视频任务。路径为统一的 `POST /v1/videos`，`model` 设为 `sd2-720p-db`。完成后从 [查询视频任务](/zh/api-reference/common/query) 的 `result.video_url` 取片。

按次计费（时长 5 / 10 / 15 秒，不参与乘价）。

## 模型

| `model` | 计费 | 时长 | 分辨率 |
| --- | --- | --- | --- |
| `sd2-720p-db` | `per_task`（按次） | **5** / **10** / **15** 秒 | 固定 **720p** |

不支持首尾帧、参考视频与参考音频。

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | `sd2-720p-db` |
| `prompt` | string | 是 | 最多 **5000** 字符 |
| `duration` / `seconds` | int | 否 | **5** / **10** / **15**；未传默认 5 |
| `aspect_ratio` / `ratio` | string | 否 | `21:9` / `16:9` / `4:3` / `1:1` / `3:4` / `9:16`；默认 `16:9` |
| `images` / `reference_images` | string[] | 否 | 参考图，最多 **10** 张 |

参考素材须为公网 `https://` URL。

## 示例

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2-720p-db",
    "prompt": "一只猫在草地上奔跑，跟拍镜头",
    "duration": 10,
    "aspect_ratio": "16:9",
    "images": ["https://example.com/cat.png"]
  }'
```
