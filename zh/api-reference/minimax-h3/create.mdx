---
title: '创建 MiniMax H3 视频'
openapi: 'POST /v1/videos'
---

异步生成 **MiniMax H3** 系列视频。使用统一入口 `POST /v1/videos`，设置 `model` 为下列之一。成功返回 `task_id`，用 [查询视频任务](/zh/api-reference/common/query) 轮询，完成后从 `result.video_url` 取片。

## 模型

| `model` | 能力 | 时长 | 分辨率 |
| --- | --- | --- | --- |
| `minimax-h3` | 文生；图片 / 视频 / 音频参考（合计最多 **9** 项） | **4～15** 秒 | `720p` / `1080p` |
| `minimax-h3-max` | 同上，Max 档 | **4～15** 秒 | `720p` / `1080p` |

计费方式为 `per_second`（按秒；费用 = 单价 × `duration`/`seconds`）。实际单价以 [模型目录](/zh/api-reference/common/model-catalog) 与创建响应中的 `cost` 为准。

## 模式判定

| 模式 | 传参 |
| --- | --- |
| 文生视频 | 不传 `images` / `videos` / `audios`，或全部传空数组 |
| 参考内容生成 | 至少传入一项图片、视频或音频参考 |

参考素材按「参考内容」使用，建议在 `prompt` 中说明每项素材的作用与编号（如图片 1、视频 1、音频 1）。本接口**不支持**首尾帧字段。

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | `minimax-h3` 或 `minimax-h3-max` |
| `prompt` | string | 是 | 生成描述，1～5000 字 |
| `duration` / `seconds` | int \| string | 是 | **4～15**；字符串亦可（如 `"10"`） |
| `aspect_ratio` / `ratio` | string | 否 | `16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`21:9`；默认 `16:9` |
| `resolution` | string | 否 | `720p`（默认）或 `1080p` |
| `images` / `reference_images` | string[] | 否 | 参考图 URL |
| `videos` / `reference_videos` | string[] | 否 | 参考视频直链 |
| `audios` / `reference_audios` | string[] | 否 | 参考音频直链 |

图片、视频、音频合计最多 **9** 项。参考素材须为公网 `https://` 直链。

## 示例

### 文生视频

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "minimax-h3-max",
    "prompt": "未来城市的夜晚，无人驾驶跑车穿过雨后的霓虹街道，电影质感",
    "aspect_ratio": "16:9",
    "resolution": "720p",
    "duration": 10
  }'
```

### 单图参考

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "minimax-h3",
    "prompt": "以图片 1 中的产品为主体，生成一支简洁的旋转展示广告",
    "aspect_ratio": "16:9",
    "resolution": "720p",
    "duration": 8,
    "images": ["https://example.com/product.png"]
  }'
```

### 图片、视频和音频组合参考

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "minimax-h3",
    "prompt": "图片 1 提供产品外观，视频 1 提供镜头运动，音频 1 控制剪辑节奏",
    "aspect_ratio": "16:9",
    "resolution": "720p",
    "duration": 12,
    "images": ["https://example.com/ref.png"],
    "videos": ["https://example.com/ref.mp4"],
    "audios": ["https://example.com/ref.mp3"]
  }'
```

## 响应

创建成功后返回统一任务结构（含 `task_id`、`status`、`cost` 等）。任务完成后通过查询接口读取 `result.video_url`。
