---
title: '创建 Kling 4.0 视频'
openapi: 'POST /v1/videos'
---

异步生成 **Kling 4.0** 视频。使用统一入口 `POST /v1/videos`，设置 `model` 为 `kling-4.0`（或直接传计费键）。成功返回 `task_id`，用 [查询视频任务](/zh/api-reference/common/query) 轮询，完成后从 `result.video_url` 取片。

## 模型

| `model` | 说明 | 时长 | 分辨率 |
| --- | --- | --- | --- |
| `kling-4.0` | 开放模型名；配合 `resolution` 计费 | **5～30** 秒 | `720p`（默认）/ `1080p` |
| `kling-4.0-720p` | 计费键：720p | **5～30** 秒 | `720p` |
| `kling-4.0-1080p` | 计费键：1080p | **5～30** 秒 | `1080p` |

计费方式为 `per_second`（按秒）。**计费秒数 = 输出时长 + 所有参考视频时长之和**（参考视频时长向上取整到秒，由请求体 `reference_video_durations` 提供；参考音频不计费时长）。实际单价以 [模型目录](/zh/api-reference/common/model-catalog) 与创建响应中的 `cost` 为准。

## 模式判定

| 模式 | 传参 |
| --- | --- |
| 文生视频 | 不传 `images` / `videos` / `audios`，或全部传空数组 |
| 参考内容生成 | 传入参考图、参考视频和/或参考音频 |

本接口**不支持**首尾帧字段。

## 参考素材限制

| 类型 | 数量上限 | 单条时长 | 单文件大小 |
| --- | --- | --- | --- |
| 图片 | **10** | — | **10MB** |
| 视频 | **5** | **≤ 30** 秒 | **50MB** |
| 音频 | **3** | **5～30** 秒 | **20MB** |

参考素材须为公网 `https://` 直链。体积限制由上传端校验；时长由 `reference_*_durations` 校验。

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | `kling-4.0` / `kling-4.0-720p` / `kling-4.0-1080p` |
| `prompt` | string | 是 | 生成描述，1～5000 字 |
| `duration` / `seconds` | int \| string | 是 | **5～30**；字符串亦可（如 `"10"`） |
| `aspect_ratio` / `ratio` | string | 否 | `16:9`、`9:16`、`1:1`；默认 `16:9` |
| `resolution` | string | 否 | `720p`（默认）或 `1080p`；传入计费键时也可从 model 推断 |
| `images` / `reference_images` | string[] | 否 | 参考图 URL，最多 **10** 张 |
| `videos` / `reference_videos` | string[] | 否 | 参考视频直链，最多 **5** 个 |
| `reference_video_durations` | int[] | 条件 | 与 `videos` **等长**，单位秒（1～30）；有参考视频时必填，用于计费累加 |
| `audios` / `reference_audios` | string[] | 否 | 参考音频直链，最多 **3** 个 |
| `reference_audio_durations` | int[] | 条件 | 与 `audios` **等长**，单位秒（5～30）；有参考音频时必填 |

## 示例

### 文生视频

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "kling-4.0",
    "prompt": "未来城市的夜晚，无人驾驶跑车穿过雨后的霓虹街道，电影质感",
    "aspect_ratio": "16:9",
    "resolution": "720p",
    "duration": 8
  }'
```

### 图片 + 视频 + 音频参考

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "kling-4.0",
    "prompt": "图片 1 提供产品外观，视频 1 提供镜头运动，音频 1 控制节奏",
    "aspect_ratio": "16:9",
    "resolution": "720p",
    "duration": 10,
    "images": ["https://example.com/ref.png"],
    "videos": ["https://example.com/ref.mp4"],
    "reference_video_durations": [5],
    "audios": ["https://example.com/ref.mp3"],
    "reference_audio_durations": [8]
  }'
```

上例计费秒数 = `10 + 5 = 15`（输出 10 秒 + 参考视频 5 秒；音频不累加）。

## 响应

创建成功后返回统一任务结构（含 `task_id`、`status`、`cost` 等）。`data.model` 为计费键（如 `kling-4.0-720p`）。任务完成后通过查询接口读取 `result.video_url`。
