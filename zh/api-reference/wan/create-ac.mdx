---
title: '创建 Wan 3 按次视频'
openapi: 'POST /v1/videos'
---

异步生成 **Wan 3** 按次视频。使用统一入口 `POST /v1/videos`，按分辨率选择计费键 `wan3-480p-ac`、`wan3-720p-ac` 或 `wan3-1080p-ac`。成功返回 `task_id`，用 [查询视频任务](/zh/api-reference/common/query) 轮询，完成后从 `result.video_url` 取片。

## 模型

| `model` | 说明 | 时长 | 分辨率 | 参考上限 |
| --- | --- | --- | --- | --- |
| `wan3-480p-ac` | 计费键：480p | **2–30** 秒 | `480p` | 图 10 / 视频 5 / 音频 5 |
| `wan3-720p-ac` | 计费键：720p | **2–30** 秒 | `720p` | 图 10 / 视频 5 / 音频 5 |
| `wan3-1080p-ac` | 计费键：1080p | **2–24** 秒 | `1080p` | 图 10 / 视频 5 / 音频 5 |

计费方式为 `per_task`（按次）。费用为该分辨率的一次单价，时长不参与乘价。实际单价以 [模型目录](/zh/api-reference/common/model-catalog) 与响应中的 `cost` 为准。

传入 `model: "wan3-ac"` 时，用 `resolution` 选择档位（`480p` / `720p` / `1080p`，默认 `720p`），任务上的 `model` 会写成对应计费键。

## 模式判定

| 模式 | 传参 |
| --- | --- |
| 文生视频 | 不传 `images` / `videos` / `audios`，或全部传空数组 |
| 参考内容生成 | 传入参考图、参考视频和/或参考音频 |

本接口**不支持**首尾帧字段。

## 参考素材限制

| 类型 | 上限 |
| --- | --- |
| 图片 | **10** |
| 视频 | **5** |
| 音频 | **5** |

参考素材须为公网可访问的 URL。

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | `wan3-480p-ac` / `wan3-720p-ac` / `wan3-1080p-ac`。也可传 `wan3-ac`，再用 `resolution` 选择档位 |
| `prompt` | string | 是 | 生成描述，1–10000 字 |
| `duration` / `seconds` | int \| string | 否 | 480p / 720p 为 **2–30**，1080p 为 **2–24**。未传时默认 **5**。字符串亦可（如 `"5"`） |
| `aspect_ratio` / `ratio` | string | 否 | `16:9`、`9:16`、`4:3`、`3:4`、`1:1`；默认 `16:9` |
| `resolution` | string | 否 | `480p`、`720p` 或 `1080p`。计费键已带分辨率时须与之一致，或不传 |
| `images` / `reference_images` | string[] | 否 | 参考图 URL，最多 **10** 张 |
| `videos` / `reference_videos` | string[] | 否 | 参考视频 URL，最多 **5** 个 |
| `audios` / `reference_audios` | string[] | 否 | 参考音频 URL，最多 **5** 段 |
| `smart_queue` | bool | 否 | 默认 `false`。为 `true` 时，近期成功率过低会先保持 `queued`，恢复后再提交（最长约 2 小时）。详见 [智能排队](/zh/api-reference/common/smart-queue) |

## 示例

### 文生视频

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3-720p-ac",
    "prompt": "雨后霓虹街道，镜头缓慢向前推进",
    "aspect_ratio": "16:9",
    "duration": 5
  }'
```

### 480p

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3-480p-ac",
    "prompt": "一只猫在草地上奔跑，跟拍镜头",
    "aspect_ratio": "16:9",
    "duration": 5
  }'
```

### 1080p 与参考图

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3-1080p-ac",
    "prompt": "参考图片中的人物走过雨后的街道",
    "aspect_ratio": "9:16",
    "duration": 5,
    "images": ["https://example.com/person.jpg"]
  }'
```

## 响应

创建成功后返回统一任务结构（含 `task_id`、`status`、`cost` 等）。`data.model` 为计费键（如 `wan3-720p-ac`）。任务完成后通过查询接口读取 `result.video_url`。
