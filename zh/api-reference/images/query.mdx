---
title: '查询图片任务'
openapi: 'GET /v1/images/{taskId}'
---

> 图片地址（`result.image_url`）保存有效期约 **3 天**，请及时转存。

创建与查询返回同一套 `data` 结构；`data.cost` 为本次扣费（积分）。

### 任务状态

| status | 说明 |
| :--- | :--- |
| `queued` / `pending` / `submitted` | 已提交，等待调度 |
| `processing` / `in_progress` / `running` | 生成中 |
| `completed` / `success` / `succeeded` | 成功，可读 `result.image_url` |
| `failed` | 失败，见 `error_message` |

```bash
curl -X GET 'https://aiplatform.ccwu.cc/v1/images/img_xxxxxxxx' \
  -H 'Authorization: Bearer sk_xxx'
```
