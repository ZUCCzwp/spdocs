---
title: '创建 GPT Image 2 任务'
openapi: 'POST /v1/images'
---

创建 GPT Image 2 异步生图任务。成功后返回 `task_id`，请用 [查询图片任务](/zh/api-reference/images/query) 轮询，完成后从 `result.image_url` 取图。

Nano Banana 系列见 [创建 Nano Banana 任务](/zh/api-reference/images/nano-banana)。

## 模型

| `model` | 说明 | 计费 |
| --- | --- | --- |
| `gpt-image-2` | 推荐写法；用 `quality` 选择档位 | 见下 |
| `gpt-image-2-low` | 低价档 | `per_task` |
| `gpt-image-2-medium` | 中档 | `per_task` |
| `gpt-image-2-high` | 高档 | `per_task` |

当 `model` 为 `gpt-image-2` 且 `quality` 为 `low` / `medium` / `high` 时，按对应 `gpt-image-2-*` 计费模型扣费。`quality` 默认 `auto`。

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 见上表 |
| `prompt` | string | 是 | 提示词，1–4000 字符 |
| `quality` | string | 否 | `auto`（默认）、`low`、`medium`、`high` |
| `n` | int | 否 | 生成张数，1–4，默认 1；费用按张数 × 单价 |
| `ratio` | string | 否 | 画面比例；也可用 `size` |
| `size` | string | 否 | `ratio` 别名 |
| `resolution` | string | 否 | 可选分辨率提示（如 `1k` / `2k`） |
| `images` | string[] | 否 | 参考图公网 URL，最多 **15** 张 |

## 示例

```bash
curl -X POST 'https://sigrunai.com/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "gpt-image-2",
    "prompt": "极简产品静物，白色背景，柔光",
    "quality": "medium",
    "n": 1,
    "ratio": "1:1"
  }'
```

成功响应示例：

```json
{
  "code": 20000,
  "msg": "提交成功",
  "data": {
    "task_id": "img_xxxxxxxx",
    "status": "queued",
    "progress": 0,
    "model": "gpt-image-2",
    "cost": 0.2,
    "result": {}
  }
}
```
