---
title: '创建 GPT Image 2.6 任务'
openapi: 'POST /v1/images'
---

创建 GPT Image 2.6 异步生图任务。成功后返回 `task_id`，请用 [查询图片任务](/zh/api-reference/images/query) 轮询，完成后从 `result.image_url` 取图。

GPT Image 2 见 [创建 GPT Image 2 任务](/zh/api-reference/images/create)。Nano Banana 见 [创建 Nano Banana 任务](/zh/api-reference/images/nano-banana)。

## 模型

| `model` | 说明 | 计费 |
| --- | --- | --- |
| `gpt-image-2.6-flare` | 更快 | `per_task` |
| `gpt-image-2.6-sunburst` | 更精细 | `per_task` |

两个模型各自按次计费。`quality` 只影响生成效果，不改变单价。实际单价以 [模型目录](/zh/api-reference/common/model-catalog) 和创建响应里的 `cost` 为准。

你也可以把质量写进模型名，例如 `gpt-image-2.6-sunburst-max`。这只是设置 `quality`，计费模型仍是 `gpt-image-2.6-sunburst`。

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 见上表 |
| `prompt` | string | 是 | 提示词，1–32000 字符 |
| `quality` | string | 否 | `auto`（默认）、`low`、`medium`、`high`、`xhigh`、`max` |
| `n` | int | 否 | 只支持 **1**。省略时按 1 张计费 |
| `ratio` | string | 否 | `auto`、`1:1`、`3:2`、`2:3`、`4:3`、`3:4`、`5:4`、`4:5`、`16:9`、`9:16`、`21:9` |
| `size` | string | 否 | `ratio` 别名。不接受像素尺寸，例如 `1024x1024` |
| `resolution` | string | 否 | 只支持省略或 `1k` |
| `output_format` | string | 否 | `png`、`jpeg`、`webp`、`svg`、`gif`。`jpg` 按 `jpeg` 处理 |
| `images` | string[] | 否 | 参考图公网 URL，最多 **16** 张 |
| `smart_queue` | bool | 否 | 默认 `false`。为 `true` 时，近期成功率过低会先保持 `queued`，恢复后再提交（最长约 2 小时）。详见 [智能排队](/zh/api-reference/common/smart-queue) |

`svg` 和 `gif` 不能带参考图。`gif` 的 `size` / `ratio` 只能省略或传 `auto`。

## 示例

### 文生图

```bash
curl -X POST 'https://sigrunai.com/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "gpt-image-2.6-flare",
    "prompt": "极简产品静物，白色背景，柔光",
    "quality": "medium",
    "n": 1,
    "ratio": "1:1",
    "resolution": "1k",
    "output_format": "png"
  }'
```

### 参考图编辑

```bash
curl -X POST 'https://sigrunai.com/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "gpt-image-2.6-sunburst",
    "prompt": "保持产品外观，换成摄影棚柔光背景",
    "quality": "high",
    "size": "16:9",
    "images": ["https://example.com/product.jpg"]
  }'
```

成功响应示例：

```json
{
  "code": 20000,
  "msg": "提交成功",
  "data": {
    "task_id": "img_xxxxxxxx",
    "status": "queued",
    "progress": 0,
    "model": "gpt-image-2.6-flare",
    "cost": 0.4,
    "result": {}
  }
}
```
