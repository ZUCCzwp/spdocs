---
title: '查询模型目录'
openapi: 'GET /v1/model/catalog'
---

返回当前启用的公开计费模型：`model_name`、展示名、类型、默认单价与计费方式。提交任务前可用本接口确认应传入的 `model`。

<Note>
本接口返回平台默认单价。若账户配置了专属价，实际扣费以创建/查询响应中的 `cost` 为准。
</Note>

### 鉴权

无需 API Key。

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `search` | string | 否 | 子串过滤 `model_name`、`display_name`、`model_type`、`remark` |

### 响应字段

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `model_name` | string | 创建接口应使用的 `model` |
| `display_name` | string | 展示名称 |
| `model_type` | string | 如 `images`、`videos` |
| `price_mode` | string | 如 `per_task`、`per_second` |
| `unit_price` | number | 平台默认单价（积分） |
| `remark` | string | 可选说明 |
| `group` | string | 可选分组 |

### 示例

```bash
curl -X GET 'https://sigrunai.com/v1/model/catalog'
```

```bash
curl -X GET 'https://sigrunai.com/v1/model/catalog?search=seedance'
```
