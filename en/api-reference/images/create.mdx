---
title: 'Create GPT Image 2 task'
openapi: 'POST /v1/images'
---

Create an async GPT Image 2 task. Poll with [Query image task](/en/api-reference/images/query) and read `result.image_url` when completed.

For Nano Banana, see [Create Nano Banana task](/en/api-reference/images/nano-banana).

## Models

| `model` | Notes | Billing |
| --- | --- | --- |
| `gpt-image-2` | Preferred; pick tier via `quality` | see below |
| `gpt-image-2-low` | Low tier | `per_task` |
| `gpt-image-2-medium` | Medium tier | `per_task` |
| `gpt-image-2-high` | High tier | `per_task` |

If `model` is `gpt-image-2` and `quality` is `low` / `medium` / `high`, billing uses the matching `gpt-image-2-*` model. Default `quality` is `auto`.

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | See table above |
| `prompt` | string | yes | 1–4000 characters |
| `quality` | string | no | `auto` (default), `low`, `medium`, `high` |
| `n` | int | no | 1–4 images, default 1; cost × count |
| `ratio` | string | no | Aspect ratio; `size` is an alias |
| `size` | string | no | Alias of `ratio` |
| `resolution` | string | no | Optional hint (e.g. `1k` / `2k`) |
| `images` | string[] | no | Public reference image URLs, max **15** |
| `smart_queue` | bool | no | Default `false`. When `true`, a very low recent success rate keeps the task `queued` until recovery (up to about 2 hours). See [Smart queue](/en/api-reference/common/smart-queue) |

## Example

```bash
curl -X POST 'https://sigrunai.com/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal product still life, white background, soft light",
    "quality": "medium",
    "n": 1,
    "ratio": "1:1"
  }'
```

Success response:

```json
{
  "code": 20000,
  "msg": "提交成功",
  "data": {
    "task_id": "img_xxxxxxxx",
    "status": "queued",
    "progress": 0,
    "model": "gpt-image-2",
    "cost": 0.2,
    "result": {}
  }
}
```
