---
title: 'Create Nano Banana task'
openapi: 'POST /v1/images'
---

Create an async Nano Banana image task. Poll with [Query image task](/en/api-reference/images/query) and read `result.image_url` when completed.

For GPT Image 2, see [Create GPT Image 2 task](/en/api-reference/images/create).

## Models

| `model` | Notes | `resolution` | Billing key examples |
| --- | --- | --- | --- |
| `nano-banana-2` | Balanced; draft through 4K | `0.5k` / `1k` / `2k` / `4k` | `nanobanana2-1k` |
| `nano-banana-2.1` | Fast iteration with better detail and text | `1k` / `2k` / `4k` | `nanobanana2.1-2k` |
| `nano-banana-pro` | Commercial detail and lighting | `1k` / `2k` / `4k` | `nanobananapro-4k` |

Billing is by resolution (`per_task`, 1 image per request). Check [Model catalog](/en/api-reference/common/model-catalog) and the create response `cost` for live prices.

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | See table above |
| `prompt` | string | conditional | Required for text-to-image; optional when `images` is set. Up to **10000** characters |
| `n` | int | no | Always **1** |
| `ratio` | string | no | Aspect ratio; `size` is an alias. Common: `1:1` / `9:16` / `16:9` / `auto` |
| `size` | string | no | Alias of `ratio` |
| `resolution` | string | no | Resolution tier, default `1k` (see table) |
| `images` | string[] | no | Public reference image URLs, max **5** |
| `smart_queue` | bool | no | Default `false`. When `true`, a very low recent success rate keeps the task `queued` until recovery (up to about 2 hours). See [Smart queue](/en/api-reference/common/smart-queue) |

## Examples

### Text-to-image (Nano Banana 2)

```bash
curl -X POST 'https://sigrunai.com/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "nano-banana-2",
    "prompt": "Cinematic sunset over a lake, golden light on distant mountains",
    "ratio": "16:9",
    "resolution": "2k"
  }'
```

### Image-to-image (Nano Banana Pro)

```bash
curl -X POST 'https://sigrunai.com/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "nano-banana-pro",
    "prompt": "Keep the product look, switch to soft studio lighting",
    "ratio": "1:1",
    "resolution": "4k",
    "images": ["https://example.com/product.jpg"]
  }'
```

### Nano Banana 2.1

```bash
curl -X POST 'https://sigrunai.com/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "nano-banana-2.1",
    "prompt": "Product poster with clear Chinese title, clean background",
    "ratio": "1:1",
    "resolution": "1k"
  }'
```

```json

  "msg": "提交成功",
  "data": {
    "task_id": "img_xxxxxxxx",
    "status": "queued",
    "progress": 0,
    "model": "nanobanana2-2k",
    "cost": 0.05,
    "result": {}
  }
}
```
