---
title: 'Query image task'
openapi: 'GET /v1/images/{taskId}'
---

> Image URLs (`result.image_url`) are kept for about **3 days**. Download promptly.

Create and query share the same `data` shape. `data.cost` is the charged amount (credits).

### Status values

| status | Meaning |
| :--- | :--- |
| `queued` / `pending` / `submitted` | Submitted, waiting. If you pass `smart_queue: true` and recent success rate is very low, the task stays queued until recovery (up to about 2 hours). See [Smart queue](/en/api-reference/common/smart-queue) |
| `processing` / `in_progress` / `running` | Generating |
| `completed` / `success` / `succeeded` | Done — read `result.image_url` |
| `failed` | Failed — see `error_message` |

```bash
curl -X GET 'https://sigrunai.com/v1/images/img_xxxxxxxx' \
  -H 'Authorization: Bearer sk_xxx'
```
