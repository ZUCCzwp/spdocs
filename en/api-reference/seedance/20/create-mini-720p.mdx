---
title: 'Seedance 2.0 Mini 720p'
openapi: 'POST /v1/videos'
---

Create a Seedance **2.0 Mini 720p** video via `POST /v1/videos` with `model` set to `sd2.0-mini-720p`. Poll [Query video task](/en/api-reference/common/query) for `result.video_url`.

Billed per task (duration only controls clip length, not the price).

## Models

| `model` | Billing | Duration | Resolution |
| --- | --- | --- | --- |
| `sd2.0-mini-720p` | `per_task` | **4–15** seconds | Fixed **720p** |

Reference videos and first/last frames are not supported.

## Request fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | `sd2.0-mini-720p` |
| `prompt` | string | yes | Up to **5000** characters |
| `duration` / `seconds` | int | no | **4–15**; default 5 |
| `aspect_ratio` / `ratio` | string | no | `21:9` / `16:9` / `4:3` / `1:1` / `3:4` / `9:16`; default `9:16` |
| `images` / `reference_images` | string[] | no | Reference images, max **9** |
| `audios` / `reference_audios` | string[] | no | Reference audios, max **3** |

Reference media must be public `https://` URLs.

## Example

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2.0-mini-720p",
    "prompt": "A cat running across a lawn, tracking shot",
    "duration": 8,
    "aspect_ratio": "16:9",
    "images": ["https://example.com/cat.png"]
  }'
```
