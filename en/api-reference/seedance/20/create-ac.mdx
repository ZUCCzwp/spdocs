---
title: 'Seedance 2.0 AC'
openapi: 'POST /v1/videos'
---

Create a Seedance **2.0 AC** video via `POST /v1/videos` with `model` set to `sd2-480p-ac` or `sd2-720p-ac`. Poll [Query video task](/en/api-reference/common/query) for `result.video_url`.

Billed per task (duration only controls clip length, not price).

## Models

| `model` | Billing | Duration | Resolution |
| --- | --- | --- | --- |
| `sd2-480p-ac` | `per_task` | **4–15** seconds | Fixed **480p** |
| `sd2-720p-ac` | `per_task` | **4–15** seconds | Fixed **720p** |

First/last frames are not supported.

## Request fields

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `model` | string | yes | `sd2-480p-ac` or `sd2-720p-ac` |
| `prompt` | string | yes | Up to **5000** characters |
| `duration` / `seconds` | int | no | **4–15**; default 5 |
| `aspect_ratio` / `ratio` | string | no | `16:9` or `9:16`; default `9:16` |
| `images` / `reference_images` | string[] | no | Up to **9** reference images |
| `videos` / `reference_videos` | string[] | no | Up to **3** reference videos |
| `audios` / `reference_audios` | string[] | no | Up to **3** reference audios |
| `smart_queue` | bool | no | Default `false`. When `true`, a very low recent success rate keeps the task `queued` until recovery (up to about 2 hours). See [Smart queue](/en/api-reference/common/smart-queue) |

Reference media must be public `https://` URLs.

## Example

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2-720p-ac",
    "prompt": "A cat running on grass, tracking shot",
    "duration": 8,
    "aspect_ratio": "9:16",
    "images": ["https://example.com/cat.png"]
  }'
```
