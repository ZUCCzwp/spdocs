---
title: 'Seedance 2.5 30s'
openapi: 'POST /v1/videos'
---

Create a Seedance **2.5 30s** video via `POST /v1/videos` with `model` set to `seedance2.5-30s`. Poll [Query video task](/en/api-reference/common/query) for `result.video_url`.

## Model

| `model` | Billing | Duration |
| --- | --- | --- |
| `seedance2.5-30s` | `per_task` | Fixed **30** seconds |

If you send `duration`, it must be `30`; otherwise it defaults to 30. First/last frame is not supported.

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | `seedance2.5-30s` |
| `prompt` | string | yes | Max **5000** characters |
| `aspect_ratio` / `ratio` | string | no | `16:9` or `9:16` only; default `9:16` |
| `images` / `reference_images` | string[] | no | Up to **30** images |
| `videos` / `reference_videos` | string[] | no | Up to **10** videos |
| `audios` / `reference_audios` | string[] | no | Up to **10** audios |

Use public `https://` URLs only.

## Example

```bash
curl -X POST 'https://aiplatform.ccwu.cc/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.5-30s",
    "prompt": "A cat running on grass, tracking shot",
    "aspect_ratio": "9:16",
    "images": ["https://example.com/cat.png"]
  }'
```
