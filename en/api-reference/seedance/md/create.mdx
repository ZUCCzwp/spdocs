---
title: 'Seedance 2.0 MD'
openapi: 'POST /v1/videos'
---

Create a Seedance **2.0 MD** video via `POST /v1/videos` with `model` set to `seedance2.0-md`. Poll [Query video task](/en/api-reference/common/query) for `result.video_url`.

## Model

| `model` | Billing | Duration |
| --- | --- | --- |
| `seedance2.0-md` | `per_task` | **5** / **10** / **15** seconds |

Output is fixed **720p**. `resolution` is ignored. First/last frame is not supported.

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | `seedance2.0-md` |
| `prompt` | string | yes | Max **6000** characters |
| `duration` | int | yes | **5**, **10**, or **15**; default 5 |
| `aspect_ratio` / `ratio` | string | no | `1:1`, `3:4`, `4:3`, `9:16`, `16:9`, `21:9` |
| `images` / `reference_images` | string[] | no | Up to **9** images |
| `videos` / `reference_videos` | string[] | no | Up to **3** videos |
| `audios` / `reference_audios` | string[] | no | Up to **3** audios |

Use public `https://` URLs only (no base64). GIF images are not supported.

## Example

```bash
curl -X POST 'https://aiplatform.ccwu.cc/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-md",
    "prompt": "Product turntable under studio lights",
    "duration": 5,
    "aspect_ratio": "1:1",
    "images": ["https://example.com/product.png"]
  }'
```
