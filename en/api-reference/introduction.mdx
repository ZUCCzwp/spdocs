## Welcome

Use AI Platform OpenAPI to create images and videos asynchronously, then poll with `task_id` until the task completes.

Available models (always check the [model catalog](/en/api-reference/common/model-catalog)):

| Type | `model` | Notes |
| --- | --- | --- |
| Image | `gpt-image-2` | Async; use `quality` or `gpt-image-2-low` / `medium` / `high` for billing tiers |
| Image | `nano-banana-2` / `nano-banana-2.1` / `nano-banana-pro` | Async; pick tier via `resolution` for billing |
| Video | `omni-10s` | Omni 10s; fixed 10s, 720p |
| Video | `seedance2.0-md` | 5 / 10 / 15 seconds |
| Video | `sd2-480p-ac` / `sd2-720p-ac` | 4–15s; per-task tiers |
| Video | `sd2-720p-dl` | Fixed 15s; per-task |
| Video | `sd2-720p-db` | 5 / 10 / 15s; per-task |
| Video | `sd2.0-mini-720p` | 4–15s; fixed 720p; per task |
| Video | `seedance2.5-30s` | Fixed 30 seconds |
| Video | `sd2.5-720p-ac` | 4–30s; fixed 720p; per task |
| Video | `wan3-480p-20s-ac` | 5–20s; fixed 480p; per task |

## API base URL

OpenAPI is served on the **same origin** as the console. Examples in these docs use:

```text
https://sigrunai.com
```

The **API keys** tab shows that origin (no path):

```text
https://sigrunai.com
```

API paths start with `/v1`. On your own domain, replace the host with the current site origin and keep the paths.

| Capability | Method and path |
| --- | --- |
| Create image task | `POST /v1/images` |
| Query image task | `GET /v1/images/{task_id}` |
| Create video task | `POST /v1/videos` |
| Create Omni 10s video | `POST /v1/videos` (`model=omni-10s`) |
| Query video task | `GET /v1/videos/{task_id}` |
| Smart queue | Optional `smart_queue` on create; see [Smart queue](/en/api-reference/common/smart-queue) |
| Upload file | `POST /v1/files` |
| Model catalog (no key) | `GET /v1/model/catalog` |
| User balance | `GET /v1/user/balance` |
| API key quota | `GET /v1/key/balance` |

## Authentication

Except for the model catalog, send:

```http
Authorization: Bearer <your API key>
```

Create keys in the console [API keys](https://sigrunai.com/console?tab=apikeys) tab.
