---
title: 'Model catalog'
openapi: 'GET /v1/model/catalog'
---

Lists enabled public billing models: `model_name`, display name, type, default unit price, and pricing mode. Use it to confirm which `model` values you can pass.

<Note>
Prices here are platform defaults. If your account has a custom price, reconcile with `cost` on create/query responses.
</Note>

### Auth

No API key required.

### Query parameters

| Param | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `search` | string | no | Substring filter on `model_name`, `display_name`, `model_type`, `remark` |

### Response fields

| Field | Type | Description |
| :--- | :--- | :--- |
| `model_name` | string | Value for the create `model` field |
| `display_name` | string | Display name |
| `model_type` | string | e.g. `images`, `videos` |
| `price_mode` | string | e.g. `per_task`, `per_second` |
| `unit_price` | number | Default unit price (credits) |
| `remark` | string | Optional notes |
| `group` | string | Optional group label |
| `capabilities` | object | Optional studio limits: `resolutions`, `ratios`, `durations`, `ref_images`, `ref_videos`, `ref_audios`, `supports_frames` |

### Examples

```bash
curl -X GET 'https://sigrunai.com/v1/model/catalog'
```

```bash
curl -X GET 'https://sigrunai.com/v1/model/catalog?search=seedance'
```
