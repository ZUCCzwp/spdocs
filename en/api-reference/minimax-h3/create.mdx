---
title: 'Create MiniMax H3 video'
openapi: 'POST /v1/videos'
---

Asynchronously generate **MiniMax H3** videos. Use the shared endpoint `POST /v1/videos` with one of the models below. On success you get a `task_id`; poll [Query video task](/en/api-reference/common/query) and read `result.video_url` when completed.

## Models

| `model` | Capabilities | Duration | Resolution |
| --- | --- | --- | --- |
| `minimax-h3` | Text-to-video; image / video / audio refs (max **9** total) | **4–15** s | `480p` / `768p` |
| `minimax-h3-max` | Same, Max tier | **4–15** s | `480p` / `768p` |

Billing is `per_second` (cost = unit price × `duration`/`seconds`). See the [model catalog](/en/api-reference/common/model-catalog) and the `cost` field on create for live unit prices.

## Mode

| Mode | How to call |
| --- | --- |
| Text-to-video | Omit `images` / `videos` / `audios`, or pass empty arrays |
| Reference-driven | Provide at least one image, video, or audio reference |

Describe each asset’s role and index in `prompt` (e.g. image 1, video 1, audio 1). First/last-frame fields are **not** supported.

## Request fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | `minimax-h3` or `minimax-h3-max` |
| `prompt` | string | yes | 1–5000 characters |
| `duration` / `seconds` | int \| string | yes | **4–15** (string form such as `"10"` is OK) |
| `aspect_ratio` / `ratio` | string | no | `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `21:9`; default `16:9` |
| `resolution` | string | no | `480p` or `768p` (default `768p`) |
| `images` / `reference_images` | string[] | no | Reference image URLs |
| `videos` / `reference_videos` | string[] | no | Public video URLs |
| `audios` / `reference_audios` | string[] | no | Public audio URLs |
| `smart_queue` | bool | no | Default `false`. When `true`, a very low recent success rate keeps the task `queued` until recovery (up to about 2 hours). See [Smart queue](/en/api-reference/common/smart-queue) |

Images, videos, and audios combined may total at most **9**. References must be public `https://` direct links.

## Examples

### Text-to-video

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "minimax-h3-max",
    "prompt": "A cinematic night drive through neon rain in a future city",
    "aspect_ratio": "16:9",
    "resolution": "768p",
    "duration": 10
  }'
```

### Single image reference

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "minimax-h3",
    "prompt": "Use image 1 as the product hero for a clean spin showcase ad",
    "aspect_ratio": "16:9",
    "resolution": "768p",
    "duration": 8,
    "images": ["https://example.com/product.png"]
  }'
```

### Image + video + audio

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "minimax-h3",
    "prompt": "Image 1 for product look, video 1 for camera motion, audio 1 for edit rhythm",
    "aspect_ratio": "16:9",
    "resolution": "768p",
    "duration": 12,
    "images": ["https://example.com/ref.png"],
    "videos": ["https://example.com/ref.mp4"],
    "audios": ["https://example.com/ref.mp3"]
  }'
```

## Response

Create returns the shared task payload (`task_id`, `status`, `cost`, …). When the job completes, poll for `result.video_url`.
