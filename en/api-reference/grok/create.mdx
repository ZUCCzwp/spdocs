---
title: 'Create Grok Imagine Video 1.5'
openapi: 'POST /v1/videos'
---

Create async **Grok Imagine Video 1.5** jobs via the shared `POST /v1/videos` endpoint. Set `model` to one of the values below. On success you get a `task_id`; poll with [Query video task](/en/api-reference/common/query) and read `result.video_url` when completed.

## Models

| `model` | Capabilities | Duration | Resolution |
| --- | --- | --- | --- |
| `grok-imagine-video-1.5` | Text-to-video; first / first-last frames; up to **7** reference images | **4–15** s | **720p** |
| `grok-imagine-video-1.5-fast` | Text-to-video; single first frame (up to 15s); multi-ref (max **10** s) | **4–15** s (multi-ref ≤10s) | **720p** |
| `grok-imagine-video-1.5-lite` | Text-to-video; single first frame; **no** multi-ref or last frame | **4–15** s | **720p** |

Billing is `per_task` (flat per job; duration only controls clip length, not the multiplier). See the [model catalog](/en/api-reference/common/model-catalog) and the create response `cost` for live prices.

## Modes

| Mode | How to send |
| --- | --- |
| Text-to-video | Omit images, or pass an empty array |
| First / first-last frames | Send `first_image` (and optional `last_image`) with `first_last_frame: true`; or put first/last URLs in `images` with `first_last_frame: true` |
| Reference mode | Send `images` / `reference_images` without `first_last_frame` (or `false`) |

Frames and reference images are **mutually exclusive**. Lite has no multi-ref or last frame; Fast has no last frame.

## Request fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | See table above |
| `prompt` | string | yes | Generation prompt, 1–5000 characters |
| `duration` / `seconds` | int \| string | yes | **4–15**; string form allowed (e.g. `"9"`) |
| `aspect_ratio` / `ratio` | string | no | `16:9`, `9:16`, `1:1`, `3:2`, `2:3`, `21:9`; default `16:9` |
| `resolution` | string | no | Default `720p` |
| `images` / `reference_images` | string[] | no | Reference image URLs; Standard / Fast up to **7** |
| `first_image` | string | conditional | First-frame URL |
| `last_image` | string | no | Last-frame URL (Standard only; requires first frame) |
| `first_last_frame` | boolean | no | `true` for first / first-last frame mode |
| `smart_queue` | bool | no | Default `false`. When `true`, a very low recent success rate keeps the task `queued` until recovery (up to about 2 hours). See [Smart queue](/en/api-reference/common/smart-queue) |

Media URLs must be public `https://` direct links.

## Examples

### Text-to-video

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "grok-imagine-video-1.5",
    "prompt": "A cinematic ad for a futuristic tech product",
    "aspect_ratio": "16:9",
    "resolution": "720p",
    "duration": 9
  }'
```

### Standard first-last frames

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "grok-imagine-video-1.5",
    "prompt": "Smooth, continuous transition between the two shots",
    "aspect_ratio": "21:9",
    "resolution": "720p",
    "duration": 9,
    "first_image": "https://example.com/first.webp",
    "last_image": "https://example.com/last.webp",
    "first_last_frame": true
  }'
```

### Fast multi-reference

```bash
curl -X POST 'https://sigrunai.com/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "grok-imagine-video-1.5-fast",
    "prompt": "Combine product and scene references into an ad",
    "aspect_ratio": "16:9",
    "resolution": "720p",
    "duration": 10,
    "images": [
      "https://example.com/product.png",
      "https://example.com/scene.png"
    ]
  }'
```

Success response example:

```json
{
  "code": 20000,
  "msg": "submitted",
  "data": {
    "task_id": "vid_xxxxxxxx",
    "status": "queued",
    "progress": 0,
    "model": "grok-imagine-video-1.5",
    "cost": 0,
    "result": {}
  }
}
```

## Polling

```bash
curl -X GET 'https://sigrunai.com/v1/videos/vid_xxxxxxxx' \
  -H 'Authorization: Bearer sk_xxx'
```

See [Query video task](/en/api-reference/common/query) for status fields. When completed, read `data.result.video_url` and download promptly.
