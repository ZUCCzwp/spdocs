# Quickstart

Create images and videos with the same async OpenAPI contract.

## Step 1: Get an API key

1. [Register](/register)
2. Open [API keys](/console?tab=apikeys)
3. Create a key and store it securely (shown once)

## Step 2: Top up

1. Open [Recharge](/recharge)
2. Complete payment before calling the API

## Step 3: Note the base URL

The console shows a base URL like (origin only, no path):

```text
https://aiplatform.ccwu.cc
```

API paths start with `/v1`. Auth: `Authorization: Bearer <API Key>`.

### Image example (GPT Image 2)

```bash
curl -X POST 'https://aiplatform.ccwu.cc/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A golden retriever running in sunlight, photorealistic",
    "quality": "medium",
    "n": 1
  }'
```

### Video example (Seedance 2.0 MD)

```bash
curl -X POST 'https://aiplatform.ccwu.cc/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-md",
    "prompt": "A cat running on grass, tracking shot",
    "duration": 5,
    "aspect_ratio": "16:9"
  }'
```

Success responses look like `{ "code": 20000, "msg": "...", "data": { "task_id": "...", "status": "queued", ... } }`.

## Step 4: Poll the task

```bash
curl -X GET 'https://aiplatform.ccwu.cc/v1/images/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

For video, use `/v1/videos/{task_id}`. When `status` is `completed`, read `data.result.image_url` or `data.result.video_url`.
