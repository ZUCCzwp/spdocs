# FAQ

## Account and billing

<AccordionGroup>
  <Accordion title="How do I get an API key?" icon="key">
    Open [API keys](/console?tab=apikeys) after login. Keys are shown once — store them securely.
  </Accordion>
  <Accordion title="What is the API base URL?" icon="link">
    Same origin as the console, e.g. `https://aiplatform.ccwu.cc` (no path). API paths are `/v1/...`. Copy the base URL from the API keys tab.
  </Accordion>
  <Accordion title="How does billing work?" icon="credit-card">
    Prepaid credits via [Recharge](/recharge). Check the [model catalog](/en/api-reference/common/model-catalog) for unit prices; reconcile charges with `data.cost` on create/query.
  </Accordion>
</AccordionGroup>

## Tasks

<AccordionGroup>
  <Accordion title="Which models are available?" icon="cubes">
    Trust the live catalog. Common IDs: `gpt-image-2` (plus low/medium/high billing tiers), `seedance2.0-md`, and `seedance2.5-30s`.
  </Accordion>
  <Accordion title="Why did my task fail?" icon="circle-exclamation">
    Typical causes: invalid parameters for that model, insufficient balance, or a temporary outage. Check `error_message` on the query response.
  </Accordion>
  <Accordion title="How do I get the result?" icon="magnifying-glass">
    Poll `GET /v1/images/{task_id}` or `GET /v1/videos/{task_id}`. When `status` is `completed`, read `result.image_url` or `result.video_url`. Links are kept about 3 days.
  </Accordion>
</AccordionGroup>
